# Auto Lead Generation — LeadForge

A standalone premium interactive **Lead → Launch** demo. This repository is intentionally independent from the other projects in the account.

## Workflow
1. **Discover** — define niche, location, lead count and buying signal.
2. **Audit** — inspect conversion gaps and business signals.
3. **Rank** — prioritize prospects with explainable scoring.
4. **Build** — generate a prospect-specific landing-page preview.
5. **Launch** — personalize WhatsApp, email or Instagram outreach.

## Run locally
Open `index.html` in any modern browser. No build step or dependencies are required.

## Demo scope
This version uses local sample data and simulated enrichment. It does **not** scrape live businesses or send outbound messages.

## Production direction
The UI can later connect to business-search providers, website/page fetchers, AI audit services, a database such as PostgreSQL/Supabase, website publishing, and approved outreach APIs.

## GitHub Pages
The repository includes a GitHub Actions workflow that publishes the root `index.html` automatically to GitHub Pages.
